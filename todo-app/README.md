# Bloom — a pink to-do list

A simple, self-contained to-do list app with a soft pink theme.

## Run it

No build step needed. Just open `index.html` in any browser.

## Features

- Add tasks with the input field or Enter key
- Click the circle to mark a task done (with strike-through)
- Hover a task to reveal the delete (×) button
- Filter by All / Active / Done
- "Clear done" removes completed tasks in one click
- Tasks are saved to your browser's local storage, so your list is still there next time you open the file

## Files

- `index.html` — structure
- `style.css` — pink theme and layout
- `script.js` — task logic (add, toggle, delete, filter, persistence)
